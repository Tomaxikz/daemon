Network Statistics Manager - V-A.1.0.0

Installation guide

Panel install using Ainx or Blueprint

The panel side can be installed by either package format. Remove the old standalone/manual panel edits first if they were previously added.

$ ainx install networkstats.ainx
$ blueprint -install networkstats

Panel cleanup if you used old manual edits

If this is a fresh Ainx or Blueprint install, skip old manual cleanup. If you previously pasted the standalone panel edits by hand, remove those old route, navigation, scheduler, and dashboard edits before installing the package.

Install the panel package

In

/var/www/pterodactyl

Execute one of these:

ainx install networkstats.ainx
blueprint -install networkstats

Ainx and Blueprint install the panel files, dashboard route, API routes, migrations, console commands, and build steps. Keep the Wings edits below as separate daemon-side changes.

Wings modifications guide

Daemon-side changes

Use the smart script for source installs

The shell installer is the most reliable automatic source-patching method for Network Statistics Manager. It downloads the daemon files, searches stable code anchors, skips edits that are already present, and builds Wings.

Use manual edits only when you want to review every change by hand. Full daemon patches touch many more Wings files and have a higher chance of conflicting with other addons.

Install the prebuilt Wings binary

Use this if you just want the daemon already patched and built.

sudo mkdir -p /etc/pterodactyl
ARCH="$([[ "$(uname -m)" == "x86_64" ]] && echo "amd64" || echo "arm64")"
curl -fL --retry 3 -o /tmp/wings \
  "https://github.com/Tomaxikz/daemon/releases/download/dev-latest/wings_linux_${ARCH}"
file /tmp/wings
sudo install -m 0755 /tmp/wings /usr/local/bin/wings
sudo systemctl restart wings

Release page: https://github.com/Tomaxikz/daemon/releases/tag/dev-latest

Recommended: run the smart installer script

Use this if you are building Wings from source and want automatic patching without manually pasting code. The script searches for stable code anchors, skips edits that are already applied, creates backups, formats Go files, and runs go build.

Run this from the root of the Wings source repo, the same folder that contains go.mod. If the script cannot find a safe anchor, it stops instead of guessing. 

curl -fL -o install_networkstats.sh \
  "https://raw.githubusercontent.com/Tomaxikz/daemon/develop/install_networkstats.sh"
chmod +x install_networkstats.sh
./install_networkstats.sh

Script file: https://github.com/Tomaxikz/daemon/blob/develop/install_networkstats.sh

Apply a Wings patch

Run these commands inside the root folder of the Wings source repo, the same folder that contains go.mod.

Use the addon patch when you only need Network Statistics Manager. Use the full patch only when you want every Tomaxikz daemon feature, because it touches more Wings files and is more likely to conflict with other addons.

Recommended: addon patch

Only applies the Network Statistics Manager Wings changes.

curl -fL -o nsm.patch \
  "https://raw.githubusercontent.com/Tomaxikz/daemon/develop/nsm.patch"
git apply --3way nsm.patch
go build
sudo systemctl stop wings
sudo install -m 0755 wings /usr/local/bin/wings
sudo systemctl start wings

Addon patch: https://github.com/Tomaxikz/daemon/blob/develop/nsm.patch

Full daemon patch

Applies all Tomaxikz Wings features, not only Network Statistics Manager.

curl -fL -o tomaxikz.patch \
  "https://raw.githubusercontent.com/Tomaxikz/daemon/develop/tomaxikz.patch"
git apply --3way tomaxikz.patch
go build
sudo systemctl stop wings
sudo install -m 0755 wings /usr/local/bin/wings
sudo systemctl start wings

Full patch: https://github.com/Tomaxikz/daemon/blob/develop/tomaxikz.patch

Edit Wings by hand

If you are not using the patch, run this from the root of the Wings source repo to add the daemon-side Network Statistics Manager files. 

curl -L -o router/nsm_router.go \
  "https://raw.githubusercontent.com/Tomaxikz/daemon/develop/router/nsm_router.go"
curl -L -o server/protocol_stats.go \
  "https://raw.githubusercontent.com/Tomaxikz/daemon/develop/server/protocol_stats.go"
curl -L -o server/protocol_monitor.go \
  "https://raw.githubusercontent.com/Tomaxikz/daemon/develop/server/protocol_monitor.go"

The protocol stats endpoint uses router/nsm_router.go and server/protocol_stats.go. Keep server/protocol_monitor.go with the manual files so the install matches the patch.

Add packet fields

In

/usr/local/dev/wings/environment/stats.go

Paste below TxBytes uint64 `json:"tx_bytes"`:

RxPackets uint64 `json:"rx_packets"`
TxPackets uint64 `json:"tx_packets"`
RxErrors uint64 `json:"rx_errors"`
TxErrors uint64 `json:"tx_errors"`
RxDropped uint64 `json:"rx_dropped"`
TxDropped uint64 `json:"tx_dropped"`

Collect packet values

In

/usr/local/dev/wings/environment/docker/stats.go

Paste below st.Network.TxBytes += nw.TxBytes:

st.Network.RxPackets += nw.RxPackets
st.Network.TxPackets += nw.TxPackets
st.Network.RxErrors += nw.RxErrors
st.Network.TxErrors += nw.TxErrors
st.Network.RxDropped += nw.RxDropped
st.Network.TxDropped += nw.TxDropped

Initialize packet values

In

/usr/local/dev/wings/server/resources.go

Paste below ru.Network.RxBytes = 0:

ru.Network.TxPackets = 0
ru.Network.RxPackets = 0

Add protocols route

In

/usr/local/dev/wings/router/router.go

Paste below server.GET("/logs", getServerLogs):

server.GET("/stats/protocols", getServerProtocolStats)

Build and restart Wings

Execute:

go build
sudo systemctl stop wings
sudo mv wings /usr/local/bin/wings
sudo systemctl start wings
